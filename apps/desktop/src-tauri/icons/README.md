# OpenUsage desktop icons

`source.svg` refines the approved OpenUsage growth mark for small sizes. The white tile provides contrast on light and dark desktops. Transparent corners preserve the rounded silhouette.

Generate the desktop PNG, ICO and ICNS assets with the official pinned Tauri CLI:

```sh
npx @tauri-apps/cli@2.12.4 icon apps/desktop/src-tauri/icons/source.svg
```

The ICO contains 16, 24, 32, 48, 64 and 256 pixel images. PNG assets cover 32, 64, 128, 256 and 512 pixels. The ICNS contains the platform sizes generated by Tauri. Mobile and Store assets are not currently packaged.

Native window decorations remain enabled. The operating system owns dragging, resizing, window buttons, snapping and keyboard window actions. The saved application theme also reaches Tauri's native theme API. Linux window managers can apply their own frame appearance.
