# Quota disclosures

October 18, 2026. The quota preview uses the existing coss Collapsible adapter for limits, Reading details, and About this preview. The first limit opens by default. Other sections stay closed until the user opens them. The scoped trigger keeps a 44-pixel target, visible focus, natural wrapping, and JetBrains Mono. It adds no animation or dependency.

The heading, synthetic-data label, unverified identity, unsaved state, read time, Read quotas, and Cancel read stay outside the collapsed sections. The provider parser, exact values, request bindings, and Rust storage remain unchanged. SQLCipher 4 and WAL remain mandatory.

The rebuilt native-test executable passed all 19 existing quota cases. Actual Tab, Space, and Enter operated the three disclosure types and their owned panels. All seven fresh captures passed review. The captures cover both themes, 360-pixel windows, missing values, cancellation, and 200% test-side text. Test-side scaling restores individual CSSOM properties under the unchanged CSP. All six measured control/value sizes returned to baseline.

The default production executable refused all three static synthetic providers before execution. Both native receipts bind their exact source, harness, and immutable executable hashes. The frontend check passed 24 contract checks and 18 renderer journeys. Fresh Rust checks passed 111 tests, strict Clippy, and formatting. One child-process helper remains intentionally ignored.

The first executable contained the separate future four-field reset-credit parser, although the frozen source had the original three-field parser. The native journey stopped before its final account read. The failed receipt, diagnostic, and initial production receipt remain historical evidence. They do not qualify the final source. Cleaning only the four local package outputs and rebuilding removed the mismatch. The unchanged native journey then passed. Cross-worktree cache reuse is the supported diagnosis; this review does not establish a Cargo defect.

[Cargo freshness documentation](https://doc.rust-lang.org/stable/nightly-rustc/cargo/compiler/fingerprint/index.html) describes mtime-based local input checks. [Package-scoped cleaning](https://doc.rust-lang.org/cargo/commands/cargo-clean.html) supplies the bounded rebuild step. Upstream [build-directory discussion](https://github.com/rust-lang/cargo/issues/14125) supplies context for shared outputs. Future source-worktree or Rust-core switches must clean local outputs before building, then freeze each executable before another build.

[The audit](../evidence/native-coss-quota-disclosure/artifact-audit.json) records exact receipts, source scopes, screenshots, and logs. This slice does not qualify strict profile reverse Tab, screen readers, live OAuth, accepted history, monitoring, reset confirmation, other platforms, or release performance. Earlier backup, persistence, and restore receipts retain their original scopes.
