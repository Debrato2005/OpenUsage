# OpenUsage 0.1.0

Draft. This version is not released. The owner adds the date and the published `SHA256SUMS` at release.

## What is in it

- The desktop app for Codex: up to 10 accounts, quotas with reset countdowns, token activity and heatmaps, alerts, export, encrypted backup and restore.
- Local logs from Claude Code and Codex, read with your consent through the bundled `ccusage` 20.0.48. This device shows totals by day, week or month over any range of up to 366 days, by hour over up to 7 days, and the sessions and projects of each tool. Only usage numbers, session IDs and times, and Claude Code project folder names are kept.
- Share images of your local totals, saved as PNG or SVG only when you select Save.
- The `openusage` command: `report`, `status`, `statusline`, `doctor` and `app`.

The opt-in leaderboard is not in this release.

`SHA256SUMS` lists the digest of each package and of the SBOM, `openusage-0.1.0-linux-x64.cdx.json`. Check the digests before you install. [Install](../install.md) gives the steps.

## Linux dependencies

- WebKitGTK 4.1 and GTK 3: `libwebkit2gtk-4.1-0` and `libgtk-3-0` on Ubuntu 24.04. The Debian package depends on both. The CLI works without them.
- A Secret Service provider, such as GNOME Keyring, for the OS key store. Without one, the app uses a password for the database key.
- A desktop notification service on the session bus, for alerts.

## Known limits

- The bundled `ccusage` runs with your user rights and is not sandboxed. See [Bundled ccusage](../../SECURITY.md#bundled-ccusage).
- Local logs cover Claude Code and Codex. The other tools that `ccusage` reads come later.
- Hourly totals cover Claude Code only, because Codex reports no hours. Codex sessions have no project, and Claude Code sessions have no reasoning count.
- Combined totals across accounts stay unavailable, because an email is not a verified identity.
- In-app deletion of local data is not available on Windows.
