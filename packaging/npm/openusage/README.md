# OpenUsage

OpenUsage shows what you used and what you have left across your AI coding tools.

```sh
npm install -g openusage
openusage app
```

This package installs the `openusage` command and the desktop app. It runs no install script and downloads nothing at install time or at run time. The binaries come in a package for each platform. This release has a package for Linux x86_64. Windows and macOS builds are previews.

See the repository for help: https://github.com/Debrato2005/OpenUsage
